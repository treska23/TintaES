# HunyuanOCR-1.5 retirado

> Esta integración está desactivada permanentemente porque la licencia de
> HunyuanOCR-1.5 excluye expresamente la Unión Europea. Los scripts se detienen
> antes de descargar o ejecutar nada. TintaES usa ahora PaddleOCR-VL 1.6 bajo
> Apache 2.0; consulta `engine/paddleocr/README.md`.

Los archivos antiguos permanecen únicamente para que instalaciones previas fallen de
forma explícita y expliquen el motivo. No existe una opción para reactivar HunyuanOCR
desde TintaES. La integración vigente está documentada en
[`../paddleocr/README.md`](../paddleocr/README.md).
